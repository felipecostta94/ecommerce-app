# 🛒 TechStore E-commerce App

Aplicação de e-commerce voltada para o segmento de hardware e tecnologia, desenvolvida com foco em alta performance, componentização modular e experiência do usuário responsiva (Mobile-First / telas 2K).

## 🚀 Sobre o Projeto

Este projeto faz parte da minha evolução técnica de transição e aprofundamento no ecossistema moderno de front-end (**React, TypeScript e Tailwind CSS**). O objetivo foi estruturar um layout de loja virtual comercial robusto, implementando componentes dinâmicos e navegação fluida.

## ✨ Features

- 📱 Layout 100% responsivo (otimizado de telas mobile até monitores 2K)
- 🎠 Carrosséis dinâmicos e isolados de ofertas e produtos (via Swiper.js)
- 🗂️ Seções estruturadas com vitrine de produtos e categorias
- ⚡ Arquitetura componentizada e escalável baseada em React Hooks
- 🎨 Estilização ágil e moderna com Tailwind CSS v4

---

## 🛠️ Tecnologias

| Tecnologia | Uso |
|---|---|
| React | Biblioteca para construção da interface SPA |
| TypeScript | Tipagem estática e segurança no código |
| Tailwind CSS v4 | Estilização utilitária e design system |
| Swiper.js | Gestão de carrosséis e banners interativos |
| Vite | Build tool e ambiente de desenvolvimento ultrarrápido |
